# Portfolio

## Citace

Při tvorbě portfolia byla použita společná konverzace s AI asistentem
GitHub Copilot ve VS Code.

Konverzace obsahovala požadavky na:

- jednoduché portfolio
- zelený terminálový vzhled
- padající jedničky a nuly
- projekty Berserk a Uncharted
- odkazy na projekty a validaci
- responzivní menu a základní HTML strukturu
